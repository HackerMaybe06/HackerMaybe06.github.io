Masaüstü Otomasyonu & LLM

KılıçV2 AI Asistan

Jarvis benzeri bir deneyim sunan, Windows işletim sistemi üzerinde derinlemesine komut çalıştırabilen ve ortam değişkenlerine göre OpenAI, Gemini, Groq veya yerel Ollama motorları arasında kesintisiz geçiş yapabilen gelişmiş masaüstü asistan mimarisi.

Python Protocol OS Automation Multi-LLM Wrapper Dataclasses

Soyutlama

Python `Protocol` yapısı kullanılarak tüm LLM sağlayıcıları tek bir çatı altında standardize edilmiştir.

Otomasyon

Doğal dil komutlarını Windows sistem API'lerine ve uygulama tetikleyicilerine dönüştürür.

Güvenlik

İnternet veya API kesintilerinde `EchoBrain` yerel yedek moduyla sistem kararlılığını korur.

Çirdek Beyin Mimarisi (brain.py)

from __future__ import annotations
from dataclasses import dataclass
from typing import Protocol
from .settings import env, env_int

SYSTEM_PROMPT = (
    "Sen KILIÇ adında bir Windows masaüstü asistanısın. "
    "Türkçe konuş, kısa ama net ol, gereksiz tekrar yapma..."
)

class Brain(Protocol):
    def generate(self, prompt: str, history: list[dict[str, str]] | None = None) -> str:
        """Verilen girdiye metin yanıtı üretir."""

@dataclass(slots=True)
class OpenAIBrain:
    api_key: str
    model: str = "gpt-4o-mini"
    max_tokens: int = 256

    def generate(self, prompt: str, history: list[dict[str, str]] | None = None) -> str:
        from openai import OpenAI
        client = OpenAI(api_key=self.api_key)
        messages = [{"role": "system", "content": SYSTEM_PROMPT}]
        if history: messages.extend(history)
        messages.append({"role": "user", "content": prompt})
        response = client.chat.completions.create(
            model=self.model, messages=messages, max_tokens=self.max_tokens
        )
        return response.choices[0].message.content.strip()

Mimari

Polimorfik Sağlayıcı Soyutlaması

`Brain(Protocol)` yapısı, uygulamanın üst katmanlarını belirli bir yapay zeka API'sine bağımlı olmaktan kurtarır. `slots=True` optimizasyonuyla derlenen dataclass'lar, mikro saniyeler seviyesinde nesne üretim hızı sağlar.

Tasarım Kalıbı: Factory Pattern / Structural Subtyping

OS Otomasyonu

Akıllı Sistem Komutu Eşleşmesi

Kullanıcı "şunu yap" dediğinde, niyet analizi (intent parsing) öncelikle yerel Windows alt sistem komutlarıyla karşılaştırılır. Eşleşme yoksa, bağlam kaybolmadan doğrudan aktif LLM katmanına yönlendirilir.

Uç Noktalar: Windows API / Process Spawning / Intent Matching

Hibrit Çalışma

Edge ve Bulut Arasında Esnek Geçiş

Proje; Groq, OpenAI ve Gemini gibi bulut API'lerinin yanı sıra tamamen internet bağımsız yerel `Ollama (llama3.1)` altyapısını destekler. Bu durum tam gizlilik ve sıfır maliyet seçeneği sunar.

Yerel Motor: HTTP /api/chat (Ollama Local Node)

Sistem Mimarisi

Gelişmiş Windows Masaüstü Entegrasyonu ve İstek Akış Dinamikleri

KılıçV2, basit bir sohbet botunun ötesine geçerek işletim sistemiyle çift yönlü konuşabilen bir ajan (agentic loop) altyapısı kurgular. `SYSTEM_PROMPT` katmanında belirlenen katı kurallar; modelin boş onaylar üretmesini engeller ve kullanıcıyı doğrudan sonuca ulaştıracak eylemlere zorlar. Teknik veya bağlamı eksik isteklerde halüsinasyonları önlemek amacıyla "bilmiyorum" mekanizması entegre edilmiştir.

`create_brain()` fabrikası, çalışma zamanında (runtime) ortam değişkenlerini (`.env`) tarayarak en uygun motoru ayağa kaldırır. API anahtarlarının eksikliği veya ağ kesintileri durumunda sistem çökmelerini engellemek üzere tasarlanan `EchoBrain` katmanı, kullanıcıya anlamlı geri bildirimler üreterek sistemi güvenli bir bekleme durumunda tutar.
