Kısa Açıklama

API-STAR

API servislerini izleme, test etme ve düzenli yönetme fikri etrafında şekillenen kısa bir proje alanı.

Proje Vizyonu

Geliştirici Deneyimini (DX) Yeniden Tanımlamak

API-STAR, modern mikroservis mimarilerinde ve backend ekosistemlerinde yaşanan "entegrasyon ve görünürlük" problemlerini çözmek amacıyla geliştirilmiş interaktif bir API yönetim ve izleme arayüzüdür. Klasik dökümantasyon araçlarının hantallığından uzak; FastAPI'nin hızını, Swagger'ın işlevselliğini ve Postman'in test gücünü tek bir hafif (lightweight) web arayüzünde birleştirir.

Neden API-STAR?

Geliştiriciler olarak zamanımızın büyük kısmını doğru çalışmayan endpoint'leri debug ederek veya güncel olmayan dökümanları okuyarak harcıyoruz. API-STAR, kod tabanınızdaki rotaları (routes) otomatik olarak parse ederek **sıfır konfigürasyon** ile yaşayan, tip güvenli (type-safe) ve asenkron çalışan bir test simülasyon evreni sunar.

Teknoloji Stack'i

Mimari Altyapı

Backend / Core FastAPI / Python 3.11+
Asenkron Yapı Asyncio & Uvicorn
Veri Validasyonu Pydantic V2
Real-time Stream WebSockets & SSE
Arayüz / UI Tailwind CSS / Vanilla JS
⚡

Anlık Tip Validasyonu ve Pydantic Entegrasyonu

İstemciden (client) gelen tüm istek gövdeleri (request body) ve query parametreleri runtime esnasında asenkron olarak valide edilir. Hatalı veri tipleri, geliştiriciye henüz API'ye ulaşmadan şematik grafiklerle raporlanır.

🔄

WebSocket Tabanlı Canlı İzleme (Monitoring)

Sistem üzerinden geçen tüm HTTP trafik yükü, gecikme süreleri (latency) ve HTTP status kodları, kurulan WebSocket tünelleri sayesinde arayüze milisaniyelik gecikmelerle yansıtılır. Darboğazlar anında tespit edilir.

🛠️

Tek Tıkla Akıllı Mock Servis Üretimi

Backend servisleriniz henüz hazır olmasa bile, tanımladığınız OpenAPI / Swagger şemalarından otomatik olarak gerçeğe yakın (faker datalı) izole Mock API endpoint'leri ayağa kaldırır, frontend süreçlerini hızlandırır.

Derinlemesine Bakış

Performans ve Ölçeklenebilirlik

API-STAR, yüksek IO gerektiren yük altında dahi minimum kaynak tüketimi sağlamak amacıyla tamamen non-blocking (asenkron) mimari felsefeyle tasarlanmıştır. Python'un modern async/await yapısı üzerine kurulu olan çekirdek motor, gelen binlerce eşzamanlı (concurrent) isteği event-loop üzerinde kuyruğa sokmadan işleyebilir.

Dökümantasyon tarafında ise statik JSON/YAML çıktıları yerine; dinamik, client-side render edilen optimize bir DOM ağacı kullanır. Bu sayede yüzlerce endpoint'e sahip devasa kurumsal API şemaları bile tarayıcıyı yormadan saliseler içerisinde yüklenebilir ve aranabilir hale gelir.
